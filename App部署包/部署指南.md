# 📱 把学习工具变成真正的 App（照着点就行）

这个文件夹里的 5 个文件就是你的"App 安装包"。整个过程约 10 分钟，全程免费、不用写代码。

## 第一步：注册 GitHub 账号（3 分钟）

1. 电脑浏览器打开 **https://github.com**
2. 点右上角 **Sign up**（注册）
3. 输入你的邮箱 → 设置密码 → 设置一个用户名（**记住这个用户名**，它就是以后 App 网址的一部分，建议用拼音，如 `zhangsan666`）
4. 按提示完成邮箱验证（去邮箱点一下验证链接）

> GitHub 是全球最大的程序员网站，微软旗下，免费、正规、安全。

## 第二步：新建仓库（2 分钟）

1. 登录后，点右上角头像旁的 **+** → 选 **New repository**（新建仓库）
2. **Repository name**（仓库名）填：`english`（或你喜欢的英文名，小写）
3. 保持 **Public**（公开）选中
4. 勾选 **Add a README file**
5. 点底部绿色按钮 **Create repository**

## 第三步：上传 App 文件（2 分钟）

1. 在仓库页面，点 **Add file** → **Upload files**
2. 打开桌面的 `App部署包` 文件夹，把里面**全部 5 个文件**拖进网页：
   - `index.html`（应用本体）
   - `manifest.json`（App 信息）
   - `sw.js`（离线缓存）
   - `icon-192.png`、`icon-512.png`（图标）
3. 等上传完，点底部绿色按钮 **Commit changes**

## 第四步：开启网站功能（1 分钟）

1. 点仓库顶部的 **⚙️ Settings**（设置）
2. 左侧菜单点 **Pages**
3. **Source** 下面选 **Deploy from a branch**
4. **Branch** 选 **main**，文件夹保持 **/ (root)**，点 **Save**
5. 等 1~2 分钟，刷新页面，顶部会出现绿色提示：
   **Your site is live at `https://你的用户名.github.io/english/`**

## 第五步：装到 iPhone（1 分钟）

1. iPhone 打开 **Safari**，输入上面那个网址（`https://你的用户名.github.io/english/`）
2. 看到蓝色的学习工具页面后，点底部**分享按钮** → **添加到主屏幕** → **添加**
3. 完成！桌面出现"英语学习"图标，点开全屏运行，**离线也能用**

## ✅ 大功告成

- 任何地点、任何网络都能打开，不依赖家里电脑
- 学习记录存在手机里，不会丢
- 以后工具升级了，把新的 `index.html` 重新上传到仓库覆盖就行（网址不变）

## ❓ 遇到问题

- 网页打不开：等 2 分钟再刷新，Pages 生效需要一点时间
- 图标没显示：检查 5 个文件是否都上传了
